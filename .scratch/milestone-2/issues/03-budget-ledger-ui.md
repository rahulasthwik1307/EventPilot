# 03: Budget Ledger Interface & Modals

**Status:** closed  
**Blocked by:** 01-budget-domain-and-calculations.md

## What to build
Build the complete Budget Ledger workspace tab, category allocation management, expense list with payment status stamps, Category Dialog, Expense Dialog, and Safe Category Deletion Dialog.

## Acceptance Criteria
- [x] Financial summary bar displaying Budget Cap, Allocated Planned, Recorded Actuals, Contingency Buffer, and Cost Per Guest.
- [x] Over-allocation and over-budget warnings with visible alerts.
- [x] Category table/cards with Add, Edit, and Delete actions.
- [x] Safe category deletion: prompt to reassign or delete associated expenses if expenses exist.
- [x] Expense list with category filter and payment status filter.
- [x] Tactile coupon stamps for `PROJECTED`, `DEPOSIT PAID`, and `SETTLED`.
- [x] Accessible modal dialogs for category and expense CRUD with validation and focus management.
- [x] Full responsiveness across mobile, tablet, and desktop viewports.
