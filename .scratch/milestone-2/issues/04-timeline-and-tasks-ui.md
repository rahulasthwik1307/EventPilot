# 04: Timeline & Tasks Interface & Modals

**Status:** closed  
**Blocked by:** 02-timeline-milestones-and-task-engine.md

## What to build
Build the Timeline & Tasks workspace tab with milestone grouping, filters (`All`, `Pending`, `Completed`, `Overdue`), Task Dialog, Milestone Dialog, and task status toggles.

## Acceptance Criteria
- [x] Timeline milestone header showing celebration date and days remaining countdown.
- [x] Chronological milestone grouping with relative offset stamps (e.g. `-90 Days`) and past-date indicators.
- [x] Task list with priority badges, effective due dates, and dynamic overdue alerts.
- [x] Quick checkbox toggle to mark tasks completed or reopen them.
- [x] Accessible `TaskDialog` supporting title, description, milestone selection, priority, and manual due date override.
- [x] Accessible `MilestoneDialog` to add custom milestones with offset days.
- [x] Filter controls with accurate counts.
- [x] Responsive behavior across desktop and touch viewports.
